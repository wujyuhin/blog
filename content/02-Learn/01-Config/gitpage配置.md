#环境配置 
- 克隆仓库
	- 复制链接 `https://github.com/wujyuhin/wujyuhin.github.io.git`
	- 打开 `cmd` 进行克隆 `git clone https://github.com/wujyuhin/wujyuhin.github.io.git`
- 配置环境
	- 首先下载 [RubyInstaller]([Jekyll on Windows | Jekyll • Simple, blog-aware, static sites](https://jekyllrb.com/docs/installation/windows/))，按网站步骤安装
		- 打开 cmd
		- 输入以下命令 `ridk install`，选择 `MSYS2 and MINGW development toolchain`
		- `gem install jekyll bundler`
		- 输入 `jekyll -v`，检查是否安装成功
- 打开Jekyll livereload server，这是下载了 RubyInstaller 之后会有的，和 cmd 差不多的命令行，
	- 新的仓库路径下有文件 `run_server.sh`
	- 切换路径，输入命令`bash run_server.sh`
